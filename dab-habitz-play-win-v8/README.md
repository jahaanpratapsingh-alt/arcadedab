# Dab Habitz Play & Win V8

Open `play-win.html` in Chrome.

## Assets
- `assets/video/arcade-entrance.mp4` — entrance film
- `assets/images/arcade-entrance-poster.jpg` — entrance poster
- `assets/audio/*.wav` — arcade SFX

## V8 changes
- Entrance video now fades/masks smoothly into the arcade lobby instead of hard-cutting.
- Sound is enabled by default. Browsers require one click/tap before audio can actually begin; the first interaction activates the entrance-film audio and game SFX.
- Entrance-film audio automatically mutes when the hero leaves view or a game opens, so it does not fight with game audio.
- Added dedicated click, collect, perfect, warning, fail, reward, roulette-spin and game-start sounds.
- Re-themed the actual game playfields around Dab Habitz / fragrance worlds, not only the outer UI.
